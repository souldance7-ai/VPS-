# 邮件客户端设置

## 推荐配置

| 项目 | 设置 |
|---|---|
| 用户名 | 完整邮箱地址 |
| 收件协议 | IMAP |
| IMAP 主机 | 邮件服务器完整域名 |
| IMAP 端口 | 993 |
| IMAP 加密 | SSL/TLS |
| SMTP 主机 | 邮件服务器完整域名 |
| SMTP 端口 | 587 |
| SMTP 加密 | STARTTLS |
| SMTP 身份验证 | 必须开启 |
| SMTP 备用 | 465，SSL/TLS |

## Outlook 手动添加

1. 文件 → 添加账户。
2. 高级选项 → 让我手动设置账户。
3. 选择 IMAP。
4. 填写本页推荐参数。
5. 用户名必须填写完整邮箱地址。
6. 收件与发件均使用同一个邮箱密码。

不要把 Poste.io 系统管理员密码填入普通邮箱账户。
