# 安全策略

## 报告安全问题

请不要在公开 Issue 中提交真实服务器 IP、域名、邮箱、密码、API 密钥、DKIM 私钥或完整日志。

报告问题时请使用以下方式替换：

- IP：`203.0.113.10`
- 域名：`mail.example.com`
- 邮箱：`user@example.com`
- 密码与密钥：`[REDACTED]`

## 项目安全边界

- 不收集遥测。
- 不上传部署报告。
- 公网 IP 自动识别会访问公开 IP 查询服务；设置 `POSTEIO_SKIP_IP_LOOKUP=1` 可禁用。
- 不读取或保存 Poste.io 管理员与邮箱密码。
- 不自动删除邮件数据。
- 修改 UFW/firewalld 前必须由用户确认。
- 备份操作会明确提示短暂停机。

请只从本仓库的 HTTPS 地址下载脚本，并在生产环境运行前阅读源码。
